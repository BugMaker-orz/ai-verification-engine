# 打包成"打开即用"的 exe 应用

本项目可以打包成 Windows 可执行文件（exe），**双击即用，对方电脑无需安装 Python**，适合分发给不会配环境的同学。

## 一、打包后的效果

```
dist/
└── AI验真引擎.exe     ← 双击这个文件
```

双击后：
1. 自动启动本地服务
2. 浏览器自动打开操作界面（http://127.0.0.1:7860）
3. 首次运行会在 exe 旁边自动生成 `rules/`（内置默认规则）和 `output/`（报告输出）
4. 用完后关闭浏览器，点 exe 窗口的 X 退出

> 第一次双击启动可能稍慢（5-15 秒），因为要解压内置资源，属正常现象。

## 二、如何打包（在自己电脑上操作）

> 打包需要在 **Windows 电脑**上执行（PyInstaller 不能跨平台编译）。整个项目只需打包一次，之后 exe 可以随意分发。

### 方法一：双击脚本（最简单）

1. 在项目文件夹里双击 `build_exe.bat`
2. 脚本自动完成：建虚拟环境 → 装依赖 → 装 PyInstaller → 打包
3. 等待 5-10 分钟，看到"打包完成！"即可

### 方法二：手动命令（想自己控制参数时）

```powershell
# 1. 进入项目目录
cd 项目目录

# 2. 创建并激活虚拟环境
python -m venv .venv
.venv\Scripts\Activate.ps1

# 3. 安装依赖和打包工具
pip install -r requirements.txt pyinstaller

# 4. 打包
pyinstaller --noconfirm --onefile --windowed --name "AI验真引擎" `
  --collect-all gradio `
  --hidden-import uvicorn.logging `
  --hidden-import uvicorn.loops.auto `
  --hidden-import uvicorn.protocols.http.auto `
  --hidden-import uvicorn.protocols.websockets.auto `
  --hidden-import uvicorn.lifespan.on `
  --add-data "rules;rules" `
  --add-data "samples;samples" `
  --add-data "config;config" `
  --add-data "docs;docs" `
  app.py
```

## 三、参数说明

| 参数 | 作用 |
|------|------|
| `--onefile` | 打包成单个 exe 文件，方便分发 |
| `--windowed` | 不显示黑色命令行窗口 |
| `--collect-all gradio` | **必须**。gradio 有大量前端资源，需要完整收集 |
| `--hidden-import uvicorn.*` | 补上 uvicorn 动态导入的模块，防止运行时崩 |
| `--add-data "rules;rules"` | 把规则库内置进 exe（首次运行自动释放到 exe 旁） |
| `--add-data "samples;..."` | 内置示例文档 |
| `--add-data "config;..."` | 内置配置目录 |
| `--add-data "docs;..."` | 内置文档（零基础指南等） |

## 四、常见问题

### Q：打包出来的 exe 有多大？

约 300-500 MB。gradio 及其依赖（fastapi、uvicorn、pydantic 等）体积较大，这是正常现象。

### Q：可以发给同学吗？对方需要装什么？

**什么都不用装**。exe 已内置 Python 运行时和全部依赖，双击即用。

### Q：对方想用 AI 功能怎么办？

对方打开界面后，在"🤖 AI 设置"面板里填自己的 API Key 即可（配置保存在 exe 旁边的 `config/` 里）。

### Q：对方能自己加规则吗？

可以。exe 首次运行会在旁边生成 `rules/` 文件夹，对方把新的规则 YAML 放进去，界面下拉框就能选到。

### Q：为什么不在 Linux/Mac 上打包？

PyInstaller 只能在本平台编译本平台的可执行文件。要在 Mac 上分发就打 Mac 版（命令里的 `;` 换成 `:`），要 Windows exe 就在 Windows 上打。

### Q：Windows 报"禁止运行脚本"？

执行一次 `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass` 再试，或改用方法二的命令方式。

### Q：exe 被杀毒软件报毒？

PyInstaller 打包的程序偶尔会被误报。可以添加信任，或用 `--onedir` 模式（文件夹形式，误报率低一些，但分发要整个文件夹一起给）。
