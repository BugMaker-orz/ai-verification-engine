# 示例文档说明

本目录包含用于演示和测试的示例合同文档。

## 文件说明

| 文件 | 说明 |
|------|------|
| `contract_main.txt` | 主合同（37行），内容相对完整，作为基准文档 |
| `contract_supplement.txt` | 补充协议，**故意设计了大量问题**，用于演示引擎的检测能力 |

## 补充协议中故意设计的问题

`contract_supplement.txt` 不是真实合同，而是为了测试和演示而构造的"问题样本"，包含：

- **跨文件冲突**：甲方名称不一致（有限公司 vs 有限责任公司）、合同金额不一致（280000 vs 320000）、签订日期不一致、生效日期缺失、合同期限不同
- **必含条款缺失**：违约责任、争议解决、保密、不可抗力、合同解除/终止、知识产权
- **禁止条款**：空白占位符未填写（critical）
- **必填字段缺失**：文档标题等

因此，用这两份文档跑验真会得到 **0 分 / F 等级**，这是预期行为，不是 bug。

## 如何使用

```bash
# 用示例文档测试引擎
python cli.py -r rules/general_contract.yaml \
  -f samples/contract_main.txt samples/contract_supplement.txt \
  -o output/ -n demo

# 或在 Web 界面中上传这两个文件
python app.py
```

## 用自己的文档测试

将本目录的文件替换为你自己的合同/协议文档即可。建议先用一份你已经人工检查过的文档跑一遍，对比引擎输出和人工检查结果，验证规则库是否适合你的场景。
